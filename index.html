복약 알림 · AI 약 정보 안내

복용 시간에 맞춰 알림을 보내고, 약 정보와 함께 먹으면 안 되는 약(병용금기)을 AI가 쉬운 말로 설명해 주는 서비스. GitHub Actions로 정해진 시간에 자동으로 알림이 나가도록 구성했습니다. 해당 프로그램은 vs코드에서 새 터미널을 불러온 후 git clone https://github.com/jungseunghyun0415/yaksok.git 명령어를 실행하신 후 git pull 명렁어를 실행하면 실행이 준비되며 그 상태에서 pip install gui/requirements.txt를 실행하시고 main.py로 이동하면 이용할 수 있습니다. 이 과정에서 main.py가 있는 yaksok/src폴더(notification 폴더 아래에 있음)에 .env폴더를 만들고 그곳에 제미나이 api키와 공공데이터포털 api키를 입력하시면 프로그램을 사용할 수 있습니다. 제가 이 프로젝트에서 맡은 부분중 가장 중요하게 생각하는 부분은 dur데이터를 연동하는 알고리즘인데 이 알고리즘은 우선 병용금기가 들어있는 BASE URL과 약의 정보가 들어있는 EASY_DRUG_URL을 통해 데이터에 접근합니다. 이 과정에서 환경변수를 통해 api키를 읽어 데이터를 열람하고 geminai를 사용합니다. 서버가 혼잡한 경우 최대 3번 재시도하며 끝내 실패할 경우 런타임 에러를 띄웁니다. 만약 열람에 성공하여 약의 데이터를 조회하면 그 약과 함께 먹으면 안되는 약, 약의 효능등을 설명해주며 약의 병용주의 데이터가 조회되지 않았을 경우에는 안전하다 단정짓지 않고 의사나 약사와 상담하라는 문구를 띄웁니다. 이러한 프로젝트를 제작하며 저는 협업의 중요성에 대해 알게 되었습니다. 팀원들과 함께 협업하면서 여러가지 오류도 일으켜 보고 병합도 진행하며 많이 힘들었지만 그 과정에서 코드가 작동하는 구조를 파악하고 openapi를 연동하는 방법도 알아내었으며 그 외에도 나 혼자만 해서는 안되겠구나 하는 생각도 들었습니다. 그리고 이러한 프로젝트를 진행하며 ai agent를 적극 활용했는데 디버깅이나 코드가 원하는 대로 작동하지 않을 때 많은 도움이 되었지만 결국 문제는 내가 해결해야 한다는 생각또한 들었습니다.
